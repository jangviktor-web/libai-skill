## 一、本集确未收篇目（仅 5 篇）

以下 5 篇经 `grep -c` 复核，在本集 `modules/01` 中命中数**均为 0**，属**真未收**；其全文已据权威源补录于 `modules/02_buyi.md`（补遗），引用时须与本集正典区分。

### 1. 折荷有赠
**著名句**：「涉江玩秋水，爱此红蕖鲜」「相思无因见，怅望凉风前」
**核验**：`折荷有赠` = 0
**来源**：《李太白集》（补遗）

### 2. 别匡山
**著名句**：「晓峰如画碧参差，藤影风摇拂槛垂」「莫怪无心恋清境，已将书剑许明时」
**核验**：`别匡山` = 0
**来源**：维基文库辑本；诸本未收，见宋熙宁元年《敕赐中和大明寺住持记》碑及《彰明县志》《江油县志》

### 3. 菩萨蛮（词）
**著名句**：「平林漠漠烟如织，寒山一带伤心碧」「何处是归程，长亭更短亭」
**核验**：`菩萨蛮` = 0；`平林漠漠` = 0；`伤心碧` = 0
**来源**：《全唐诗》卷八九〇（词）。旧题李白，与《忆秦娥》并称「百代词曲之祖」，然**本集为诗总集，不收词**。

### 4. 忆秦娥（词）
**著名句**：「箫声咽，秦娥梦断秦楼月」「西风残照，汉家陵阙」
**核验**：`忆秦娥` = 0；`箫声咽` = 0；`秦楼月` = 0
**来源**：《全唐诗》卷八九〇（词）。同上，本集不收词。

### 5. 桂殿秋（词，二首）
**著名句**：「仙女下，董双成」「河汉女，玉炼颜」
**核验**：`桂殿秋` = 0
**来源**：《全唐诗》卷八九〇（词）。同上，本集不收词。

## 二、引用纪律（须与 §一 配套遵循）

1. **本集未收 ≠ 李白没写过。** 上列 5 篇只能表述为「**本篇不在本集 / 本集未收**」，**绝对不可**反推为「李白无此作」「此为伪托」，也不得因未收而降低其通行本的流传地位。
2. 上列 5 篇之句**不得冒充本集原文**引用；确需引用时，须标注「本集未收，据 `modules/02_buyi.md` 补录（来源：…）」。
3. **不得伪造出处行号**；本集内引句须 `grep -n` 命中后再写。
4. 篇名一律**从本集**：如《客中作》本集作《客中行》、《临终歌》本集作《临路歌》，引篇名以本集为准。
