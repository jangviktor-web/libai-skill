## 一、核心意象群（16 组）

### 1. 月
**象征**：时间的恒久者、孤独的见证者、故乡的召唤者；常在"我—月—影"关系中充当唯一知音。**情感**：孤高/思乡/宇宙意识。**频次**：437（全集最高频名物字之一）。

|---|---|
| 床前明月光 / 举头望明月 / 低头思故乡 | 《静夜思》 |
| 小时不识月，呼作白玉盘 / 又疑瑶台镜 | 《古朗月行》 |
| 举杯邀明月，对影成三人；花间一壶酒 | 《月下独酌四首》 |

| 青天有月来几时 / 今人不见古时月 / 月光长照金樽里 | 《把酒问月》 |

| 了见水中月 | 《陪族叔当涂宰游化城寺升公清风亭》 |

### 2. 酒
**象征**：不是消愁剂，而是"确认自我存在"的仪式——饮酒即公开拒绝权贵秩序与功名逻辑。**情感**：豪纵/愤懑/及时行乐。**频次**：214。

### 4. 鹏
**象征**：被贬抑的绝对自由与孤注一掷的天才自信，是"自我神圣化"的极致符号。**情感**：自许/悲壮/命定的失败感。**频次**：仅 7，但两度位居名篇。

| 诗句 | 出处 |
