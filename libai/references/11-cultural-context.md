## 〇、语境速览：一个诗人背后的六套装置

| 装置 | 制度事实 | 对李白诗的直接后果 |
|---|---|---|
| 科举 | 进士科岁取二三十人，不糊名、行卷风气盛（《唐六典》相关记载；唐代荐举制与科举并行） | 李白**由干谒—征召入朝**，非进士出身；诗中多"知遇/知己"母题 |
| 干谒 | 献诗文于权贵求荐，称"干谒"，被视为入仕"终南捷径" | 《与韩荆州书》式的自我推销姿态渗进诗；"弹剑作歌""曳裾王门" |
| 隐逸 | 隐终南、少室以博名，朝廷征召处士（《新唐书·卢藏用传》） | 隐居＝待价，故其山水诗常含不安分 |
| 道教 | 李唐尊老子为祖，道教为事实国教；道士受箓、隶宗正寺（《隋书·经籍志》《中国道教脉络》） | 受箓、"谪仙人"身份、游仙诗大系统 |
| 任侠 | 初盛唐任侠为"四大思潮"之一（陈伯海说）；《新唐书》本传"喜纵横术，击剑，为任侠，轻财重施" | 剑、侠、纵横语汇与"轻儒"声口 |
| 驿道／乐府 | 全国驿 1,600 余所，三十里一驿（《唐六典》系记载）；开元二年置教坊、梨园（李清照《词论》引唐声诗制度） | 漫游的地理骨架 + 诗可入乐的演唱语境 |

> **一句话总结**：李白的诗不是"个人抒情"，而是**干谒者的自荐书、受箓者的游仙图、送别者的酒与柳、侠客的剑与诺、乐工的歌词、驿路上的题壁**——这六种场合的总和。

## 一、盛唐文士的五条生存通道

### 1.1 科举：李白绕开的那条正门

- 唐代进士科**年取极寡**（约二三十人），且试卷**不糊名**，声望与人脉先于文才；举荐之途甚至比考试更畅（时人多谓举荐一途占录取之半）。孟浩然"欲济无舟楫，端居耻圣明"（《望洞庭湖赠张丞相》）即典型干谒语。
- 李白**没有科举记录**。学界主流推测与其家世有关（其父李客"逃归于蜀"，家世隐晦，或被目为商贾之家；而唐制工商之家不得预于士），故其一生仕进走的是**献赋、干谒、隐逸待召**三条旁门。
- **源集内旁证**：李白曾送两位从弟赴举进京——卷十六《鲁中送二从弟赴举之西京》"送君日千里"、"舞袖拂秋月"。**他自己不赴举，却写别人赴举**，这正是理解其"布衣卿相"执念的入口。

### 1.2 干谒求荐：把诗歌当作求职信

- 干谒＝将述志书信或代表诗作呈送权贵、名流，求其荐举。李白有名篇《与韩荆州书》（文，"生不用封万户侯，但愿一识韩荆州""十五好剑术，遍干诸侯；三十成文章，历抵卿相"），可惜此文**不在诗集中**，引用时须标为"文，非本集"。
- **源集可核的干谒姿态**：

| 诗句 | 出处 | 语境义 |
|---|---|---|
| 弹剑作歌奏苦声 / 曳裾王门不称情 | 卷二《行路难二首·其二》 | "曳裾王门"即寄食权门之态，与"不称情"的矛盾是干谒者的基本心理 |
| 长揖韩荆州 | 卷九《忆襄阳旧游赠马少府巨》 | 长揖而不拜，是李白式干谒的姿态洁癖 |
| 献书入金阙 | 卷十八《金门答苏秀才》 | 献书＝投递自我，直入金门 |
| 今乘款段诸侯门 | 卷十《江夏赠韦南陵冰》 | 干谒的交通工具与门第落差 |
| 徒干五诸侯 | 卷十五《送王屋山人魏万还王屋 并序》 | 干谒失败率之自陈 |
| 弹剑徒激昂 | 卷八《赠崔郎中宗之 时谪官金陵》（按：卷八同篇内见"弹剑徒激昂"） | "弹剑"成其固定动作 |

- **写作学后果**：干谒要求"既要表明目的，又要委婉含蓄"，而李白的失败常在于最后一联的傲岸情绪泄出——这恰是其诗"前半恭谨、结尾狂放"结构张力的社会来源。

### 1.3 隐逸与"终南捷径"

- 出处：《新唐书·卢藏用传》——卢藏用举进士不第，与兄隐终南、少室，"学练气，为辟谷"，道士司马承祯将还山，藏用指终南曰"此中大有佳处"，承祯答"以仆观之，仕宦之捷径耳"；时人称卢为"随驾隐士"。唐时隐士中"终生不仕者不过陆羽、崔瑾二人"。
- 操作逻辑：隐于距长安极近的终南（主峰距城百里内，快马半日）→ 与长安名士唱和博名 → 地方官推荐或被征召 → 直接授清要官。
- **李白的两条源集证据**：
  - 卷十九《下终南山过斛斯山人宿置酒》——"下终南山"三字即在写**从隐居点（终南）返回长安圈**的路径。
  - 卷二十二《春归终南山松龛旧隐》"我来南山阳"——终南有其"旧隐"。
  - 卷七《玉真仙人词》、卷八《玉真公主别馆苦雨赠卫尉张卿二首》——玉真公主（玄宗妹，女道士）的别馆是隐士与宫廷之间的接口；史载李白曾于楼观延生观谒见玉真公主并献《玉真仙人词》（今说见新、旧唐书系年与《李翰林集序》）。
- **源集可核的隐逸语汇**：卷一《古风》"青门种瓜人"（邵平典，隐与仕的反讽）、"且学南山豹"（卷十一《经乱后将避地剡中留赠崔宣城》）、卷三《山人劝酒》"归来商山下"、卷十八"角巾东出商山道"（《答杜秀才五松见赠》）、卷二十一《商山四皓》、卷十七《宣州谢朓楼饯别校书叔云》结句"明朝散发弄扁舟"。

### 1.4 幕府与边功：另一条越考捷径

- 唐制：文人入节度使幕府（"入幕"）任判官、掌书记，是科举之外最快的仕进路；高适、岑参皆由此途。岑参《初过陇山途中呈宇文判官》"一驿过一驿，驿骑如星流"即写此途的交通节奏。
- **源集证据极密**（"幕"字 15 见）：卷十六《送程刘二侍郎兼独孤判官赴安西幕府》"安西幕府多才雄"、《送张遥之寿阳幕府》、卷十七《送赵判官赴黔府中丞叔幕》"才高幕下去"、《宣城送刘副使入秦》、卷十《在水军宴赠幕府诸侍御》、《赠张相镐二首》"尽为入幕珍"、卷八《赠郭将军》"美人向月舞罗衣"。
- 边地语汇：卷二《北风行》"燕山雪花大如席""幽州思妇十二月"、卷三《幽州胡马客歌》、卷二《胡无人》（另有卷二十五《胡无人行》）、卷十九《幽州胡马客歌》系胡地题材。

### 1.5 漫游：把一生过成一条路

- 李白自述（《上安州裴长史书》，文）"曩昔东游维扬，不逾一年，散金三十余万"；魏颢《李翰林集序》记其"少任侠"；范传正《新墓碑》记其"少以侠自任，而门多长者车"。
- 漫游的实质＝**流动的干谒＋求仙＋交友＋寻景**四合一。源集显示其游踪关键词：金陵（40 处）、洞庭（27 处）、峨眉（13 处）、三峡（10 处）、梁园（8 处）、荆门（5 处）——**诗即行旅日志**。

## 二、道教与游仙文化

### 2.1 唐代道教为何是"事实国教"

- 唐高祖**武德八年（625）**诏定三教序：道教第一、儒教第二、佛教第三；太宗**贞观十一年（637）**再申尊崇（《中国全史·隋唐五代》系年）。
- 皇室追尊老子李耳为"玄元皇帝"；玄宗开元中诏两京及诸州各置玄元皇帝庙，**天宝三载改天下诸郡玄元庙为紫极宫**；开元二十五年（737）"道士女冠隶宗正寺，僧尼令祠部检校"，道士地位制度化（《中国道教脉络》）。
- 玄宗曾亲受法箓、以道士为师；玉真公主、杨贵妃（道号"太真"）皆入道。唐代"六位皇帝吃丹药中毒而亡"（《长安三万里》相关评述引统计）。
- **含义**：道教不是李白的个人信仰偏好，而是**干禄、交游、宫廷趣味共同认账的上层通行证**。

### 2.2 受箓：一个诗人的"入编"

- **天宝三载（744）**，李白先赴安陵请道士**盖还**造真箓，又经陈留采访使李彦允介绍，在**齐州（今济南）紫极宫**由北海天师**高如贵**授道箓，正式入道籍（李阳冰《草堂集序》："请北海高天师，授道箓于齐州紫极宫"）。
- 仪轨严酷：受箓者反剪双手绕坛而行、念诵忏悔，"洁斋"素食清水，昼夜不息，历七日乃至十四日（《隋书·经籍志》记法；郭沫若据此论其"精神和肉体都极度疲惫"，易生幻视幻听）。
- **源集双重铁证**（诗题即仪式的产物）：
  - 卷九《访道安陵遇盖还为余造真录临别留赠箓》——"为我草真箓"、"学道北海仙"、"仙人识青童"。
  - 卷十六《奉饯高尊师如贵道士传道录毕归北海箓》——受箓毕而为传箓师饯行，**"饯别诗"与"道箓"在此合流**。
- 李白诗中亦录道教地景：卷二十三《寻阳紫极宫感秋作》（紫极宫＝老子庙，见 2.1 改名之制）、卷八《赠嵩山焦炼师 并序》（记"嵩丘有神人焦炼师者，不知何许妇人也"）、元丹丘系列十一题（卷六《元丹丘歌》、卷十八《以诗代书答元丹丘》、卷二十四《题元丹丘颍阳山居 并序》等）。

### 2.3 炼丹服食：游仙诗的物质底座

| 诗句 | 出处 | 所写 |
|---|---|---|
| 吾将营丹砂 / 永与世人别 | 卷一《古风五十九首·其五》 | 以炼丹为决裂世俗的宣言（同篇"仰望不可及 / 苍然五情热"） |
| 炼丹砂 / 丹砂成黄金 | 卷二《飞龙引二首》 | 飞升叙事的工艺细节 |
| 炼火烧金丹 | 卷十一《赠嵩山焦炼师》（篇内句） | 作为炼师的赠答 |
| 早服还丹无世情 | 卷十三《庐山谣寄庐侍御虚舟》 | "还丹"与弃世同步 |
| 结发受长生 / 仙人抚我顶 | 卷十《经乱离后天恩流夜郎忆旧游书怀赠江夏韦太守良宰》 | 把入道写成宿命 |
| 身在方士格 / 吾求仙弃俗 / 才术信纵横 | 卷九《草创大还赠柳官迪》 | 造"大还"内丹的自述与身份登记 |
| 学道三千春 | 卷十八《答杜秀才五松见赠》篇内 | 时间尺度的仙化 |
| 服药求仙事不违 | 卷二十三《题雍丘崔明府丹灶》 | 他人丹灶的现场记录 |
| 家僮丹砂学凤鸣 | 卷二十四《其四》 | 丹砂入名的家内细节 |
| 学道飞丹砂 | 卷二十二《落日忆山中》 | 退隐与炼丹互为出口 |

- 频次佐证：`仙` 104、`丹` 89、`道` 211。葛立方《韵语阳秋》评："李白《古风》两卷近七十篇，身欲为神仙者，殆十三四。"

### 2.4 洞天福地说与游仙诗的空间语法

- 司马承祯（茅山宗第十二代宗师，曾谓李白"有仙风道骨"，李白《大鹏遇希有鸟赋》即赠其人）主张五岳各置真君祠，其**"洞天福地"说**使名山成为可进入的神仙领土（《中国道教脉络》；柏夷 Stephen Bokenkamp 关于李白道箓与"豁落七元符"的研究）。
- 源集由此出现两类空间：**天上的**（蓬莱 14 见、瑶台 11 见、昆仑、羽人、仙人 32 见）与**地上的**（庐山、嵩山、黄山、剡中、天柱石）。二者靠"洞天"接口——卷十《梦游天姥吟留别》所写的"洞天"意象即此说的诗化（**该篇不在源集，见文末清单**）；源集内可核的同类写法如卷十三《庐山谣寄庐侍御虚舟》"遥见仙人彩云里""早服还丹无世情"、卷七《怀仙歌》"仙人浩歌望我来"、卷二十一《下途归石门旧居》"余尝学道穷冥筌"。

### 2.5 语境→创作接口

1. **游仙＝失意的代偿语法**：功业受挫处，必有仙山接续（《草创大还》的自夸紧接于出京之后）。
2. **受箓＝身份道具**：诗题、赠答对象（炼师、道士、女冠）自带宗教社交网络。
3. **丹药＝时间修辞**："三千春""四万八千岁"式的超长时距来自服食想象。

## 三、酒宴与送别文化

### 3.1 唐人饯别的完整程式

隋唐行旅前有**祖送（祭路神）→ 饯酒（饮饯）→ 折柳 → 送行 → 酌别**五步；归来则设宴洗尘，谓之**"软脚"**（《中国全史·隋唐五代》；杨炯《送并州旻上人诗序》"祖送于青门之外"、王维《齐州送祖三》"祖帐已伤离"皆其证）。饯别常在**五更拂晓**（王维《送元二使安西》"渭城朝雨浥轻尘"）。

- **源集对应**：卷十五《对雪奉饯任城六父秩满归京》"饯离驻高驾"、卷十六《却回栖霞山留饮赠之》"贤豪相追饯"、卷十七《饯校书叔云》《宣州谢朓楼饯别校书叔云》、卷二十一《下途归石门旧居》"岁时同饯五侯门"、卷二十四《题瓜州新河饯族叔舍人贲》——"饯"字成篇题，是风俗直接进入标题。

### 3.2 灞桥／灞陵：长安东出的"销魂桥"

- 《三辅黄图·桥》："灞桥在长安东，跨水作桥，汉人送客至此桥，折柳赠别。"唐时长安东 30 里之灞桥，两岸十里长堤"一步一柳"，东行多于此分手，故称"销魂桥"；"柳"谐"留"，折柳即留客（《中国民俗史·隋唐卷》）。
- **源集证据**：
  - 卷十六《灞陵行送别》——"送君灞陵亭 / 灞水流浩浩"，并直入"骊歌愁绝不忍听"。
  - 卷二十四《劳劳亭》——"天下伤心处 / 劳劳送客亭 / 春风知别苦 / 不遣柳条青"；卷六《劳劳亭歌》题下自注"在江宁县南十五里，古送别之所"。
  - 卷二十四《春夜洛城闻笛》——"此夜曲中闻折柳 / 何人不起故园情"；"折柳"已是**曲名兼风俗**。
  - 卷五《折杨柳》（乐府题）、卷二十五《送袁明府任长沙》"别离杨柳青"。

### 3.3 胡姬酒肆：都市饮酒空间

- 长安东西两市与坊间酒肆多胡人当垆；进士放榜后"以红笺名纸游冶"于平康坊，"京都侠少萃集于此，时人谓此风流薮泽"（王仁裕《开元天宝遗事》）。
- **源集证据**：卷五《少年行二首·其二》"五陵年少金市东 / 银鞍白马度春风 / 落花踏尽游何处 / 笑入胡姬酒肆中"；卷五《白鼻》"挥鞭直就胡姬饮"；卷二《前有一樽酒行二首·其二》"胡姬貌如花 / 当垆笑春风 / 笑春风"；卷十一《醉后赠王历阳》"双歌二胡姬"；卷十六《送裴十八图南归嵩山二首·其一》"胡姬招素手"。胡字全书 121 见，胡姬、胡马、胡乐共构**盛唐都市的异域感**。

### 3.4 曲江游宴与上巳、重九

- 玄宗开元间扩建曲江池（紫云楼、彩霞亭、杏园），每年**上巳（三月三）、重九**皇帝于曲江赐宴群臣并许士庶僧道同游，"鲜车宝马，摩肩接毂"，杜甫《丽人行》"三月三日天气新，长安水边多丽人"即写其盛（湖北省图书馆藏《倾动皇州的曲江游宴》）。
- 这类场合要求"应制"写作——源集卷六《侍从宜春苑奉诏赋龙池柳色初青听新莺百啭歌》、卷十六《送贺监归四明应制》即宫廷场合诗，与其乐府、游仙诗是**两套语言**。

### 3.5 宴饮中的乐舞与"观妓"

- 唐人宴集必有歌妓、舞妓与器乐。李白本人亦起舞：卷六《东山吟》"酣来自作青海舞 / 秋风吹落紫绮冠"；并熟稔舞名——卷七《草书歌行》"何必要公孙大娘浑脱舞"。
- **篇题即场景**：卷十九《秋猎孟诸夜归置酒单父东楼观妓》《邯郸南亭观妓》《在水军宴韦司马楼船观妓》、卷二十四《出妓金陵子呈卢六四首》（"楼中见我金陵子""小妓金陵歌楚声"）、卷十九《宴郑参卿山池》"舞影回清池"、卷六《梁园吟》"舞影歌声散绿池"、卷八《赠郭将军》"美人向月舞罗衣"、卷二十二《对酒醉题屈突明府厅》"舞袖为君开"。
- "舞"字全书 76 见——**盛唐酒宴是一台小型演出，诗常是其中一段台词**。

### 3.7 "谪仙人"与金龟换酒：酒宴现场生产的神话

- 卷二十二《对酒忆贺监二首 并序》序（**源集原文**）："太子宾客贺公，于长安紫极宫一见余，呼余为**谪仙人**，因**解金龟换酒**为乐。殁后对酒，怅然有怀而作是诗。"正文："四明有狂客 / 风流贺季真 / 长安一相见 / 呼我谪仙人 / 金龟换酒处 / 却忆泪沾巾"。
- **意义**：李白最著名的称号产生自一次酒楼相遇，并被他自己写进诗的序里——**酒宴既是社交场，也是身份命名场**。源集另有卷十八《答湖州迦叶司马问白是何人》"青莲居士谪仙人 / 酒肆藏名三十春"，把"酒肆"与"谪仙"两重身份合写。

## 四、任侠与纵横之风

### 4.1 史实底座

- 陈伯海：任侠应与儒、释、道并列为唐代社会**四大思潮**，相摩相戛、互为表里。
- 《新唐书·文艺传》本传："（白）喜纵横术，击剑，为任侠，轻财重施。"魏颢《李翰林集序》更记其"少任侠，手刃数人"；范传正《新墓碑》"少以侠自任，而门多长者车"。李白自述见《上安州裴长史书》（文）：扬州散金三十万周济落魄者、洞庭葬亡友。
- 社会原因（《文史知识》1990 年第 1 期）：①李唐王室胡化深、尚武好侠；②游牧民族内附使雄杰骠悍之风入内地，唐人"颇以走马骑射为夸"；③帝国富强激发英雄气与解放精神，古游侠"奋烈践义、毫无羁勒"恰与之契合。
- 量级：初盛唐"歌颂游侠的诗歌留存至今的有百首之多，相当于汉末到隋四百年间同类诗歌的两倍"；《全唐诗》以"少年行"为题者近 60 首。

### 4.2 源集的侠谱与侠气

| 诗句 | 出处 | 文化注 |
|---|---|---|
| 赵客缦胡缨 / 吴钩霜雪明 / 银鞍照白马 / 飒沓如流星 | 卷二《侠客行》 | 侠的外形学：胡缨、吴钩、白马 |
| 十步杀一人 / 千里不留行 / 事了拂衣去 / 深藏身与名 | 卷二《侠客行》 | 侠的伦理：功成而隐名 |

| 击筑饮美酒 / 剑歌易水湄 / 经过燕太子 / 结托并州儿 | 卷五《少年行二首·其一》 | 荆轲—燕太子丹的复仇谱系 |

- **延伸**：纵横之风与干谒是一体两面——"纵横术"即游说术，侠是身、纵横是口。卷八《述德兼陈情上哥舒大夫》"纵横逸气走风雷"、卷十七《送张秀才谒高中丞 并序》"酒酣舞长剑"（一本作"纵横"）、卷十七《宣城送刘副使入秦》"纵横两无疑"。

### 4.3 边界提示（供 skill 反模式使用）

- 源集对《少年行》《猛虎行》等篇保留"伪作"按语（"此诗严粲云是伪作""此诗萧士赟云是伪作"），引用侠类名句时**宜优先取《侠客行》**。
- 任侠并非无政府主义：陈子昂《复仇议》以"按法处刑＋旌表其孝"两全，说明唐代任侠被**收编进国家伦理**。李白的侠气常以"报国—边功"为出口（卷三《司马将军歌》"将军自起舞长剑"、卷二《胡无人》）。

## 五、乐府与音乐

### 5.1 唐人所谓"乐府"有三义

①**音乐机构**：太常寺，及开元二年（714）从中分离的教坊、梨园；②**机构所唱歌辞**（含文人歌诗与曲子词）；③**拟乐府旧题的诗体**（《新乐府辞研究》《"声诗"概念与李清照〈词论〉解读》）。玄宗时"玄宗度曲，欲造乐府新词，亟召白，白已卧于酒肆矣。召入，以水洒面，即令秉笔，顷之成十余章"（《旧唐书·李白传》）——**"乐府"在此指梨园。**

### 5.2 制度沿革与"诗入乐"的现场

- 开元二年玄宗置左右教坊（右教坊光宅坊主歌诗，左教坊延政坊主舞蹈），后又设**梨园**，选乐工宫女数百，亲教之，谓"皇帝梨园弟子"（《唐会要》《乐府杂录》；李清照《词论》"乐府、声诗并著，最盛于唐"）。任半塘《唐声诗》统计现存唐声诗调 154，**80% 创调于盛唐**；天宝三载芮挺章编《国秀集》，选取标准即"可被管弦者"。
- **李白作为宫廷词人**：《唐国史补》"玄宗令撰乐辞，醉不可待，以水沃之……索笔一挥十诗章"；《本事诗》记玄宗命作《宫中行乐》五言律十首；《松窗杂录》记李龟年持金花笺宣赐李白进《清平调》三章，"上命梨园弟子约略调抚丝竹，遂促龟年以歌"。
- **⚠️ 重要**：《清平调》《宫中行乐词》**均不在本诗全集**（`grep 清平调 = 0`）。此类名篇只能作**史实引用**（证李白为宫廷作词），不得作为源集引诗。
- 民间传唱机制：《集异记》"旗亭画壁"——王昌龄、高适、王之涣于旗亭听伶人歌唱以赌诗名；王维《送元二使安西》入乐为《阳关曲》传唱。**"诗写得好"的检验标准之一是被歌女演唱。**

|---|---|---|
| 箜篌 | 箜篌所悲竟不还 | 卷二《公无渡河》（另有卷二《箜篌谣》） |

| 笛 | 谁家玉笛暗飞声 / 散入春风满洛城 | 卷二十四《春夜洛城闻笛》 |

- 卷二《公无渡河》以"箜篌所悲竟不还"收束——**写的是箜篌曲的悲声，正是乐府入乐的证据**。卷三《乌栖曲》"吴歌楚舞欢未毕"、卷二十四《越女词五首·其三》"笑入荷花去 / 见客棹歌回"、卷十一《赠汪伦》系"忽闻岸上踏歌声"——歌唱发生在江上、酒边、送别处。

### 5.4 李白在乐府史上的位置

- 胡震亨《唐音癸签》："太白于乐府最深，古题无一弗拟，或用其本意，或翻案另出新意，合而若离，离而实合，曲尽拟古之妙。"
- 许学夷《诗源辩体》卷十九："五七言乐府，太白虽用古题，而自出机轴，故能超越诸子。"
- 沈德潜《唐诗别裁》所谓"借古人体制写自己胸臆"。
- **源集结构本身即证据**：卷二至卷五（乐府 30＋37＋44＋38＝149 题）几乎把乐府诸题扫了一遍；卷一《古风五十九首》"圣代复元古 / 垂衣贵清真……我志在删述 / 垂辉映千春"是其**复古诗学宣言**。

### 5.5 演唱语境对写作的三重约束（可作生成规则）

1. **可歌性**：句子长短相济、多用叠句（"笑春风。笑春风。"卷二《前有一樽酒行》；"一杯一杯复一杯"）；清人谢榛"唐人歌诗，如唱曲子，可以协丝簧，谐音节"。
2. **场面性**：诗常常为某个宴席、某次饯别、某个楼台而作——篇题即场景（本集 366 处"赠/送"）。
3. **传播性**：题壁、赠答、传唱是唐诗的传播三通道；源集卷十八《乘醉着紫绮裘乌纱巾与酒客数人棹歌》这样的长题，本身就是一则"现场记录"。

## 六、漫游与交通：李白足迹的地理骨架

### 6.1 驿传制度（数字与规范）

- 管理：中央尚书省兵部**驾部郎中**统管，地方州县长官兼理；驿分**陆驿、水驿、水陆兼驿**三类。
- 规模：**凡三十里一驿**（地势险阻或须依水草处不限）；全国置驿约 **1,600 余所**（《唐六典》系记载；诸书统计略有出入，常见数字为 1,629／1,639／1,643 所，其中陆驿 1,297、水驿 260、水陆兼驿 86）。
- 配置：京城都亭驿备马 75 匹，诸道之驿视繁闲分六等（60/45/30/18/12/8 匹）；水驿备船繁者四只。
- 法令：《唐律疏议》"驿使稽程"一日杖八十；紧急军情加三等。文书分"驿递"（常行）与"驰驿"（加急，日行 500 里）。安禄山范阳起兵，3000 里军报**六日达长安**（《中国档案史专题研究》）。岑参《初过陇山途中呈宇文判官》："一驿过一驿，驿骑如星流。平明发咸阳，暮及陇山头。"

### 6.2 以长安为中心的七条干道

西北至安西都护府（丝绸之路）、东北至营州、西南经剑南通南诏、南经荆襄至广州、东南沿运河至扬州，另有长安—汉中—成都（蜀道）与长安—太原—幽州线（《中国通史·隋唐卷》；柳宗元《馆驿使壁记》"天下之道涂，毕出于邦畿之内"）。

### 6.3 长江水路与三峡：险与速

- 水驿备船，长江为东西主干；洞庭、鄱阳、汉水、湘江、赣江附之，大运河贯通南北。沿驿道另有私人店肆，"每店皆有驴赁客乘，倏忽数十里，谓之驿驴"（《中国通史·隋唐卷》），"远适数千里，不持寸刃"。
- **源集证据**（三峡—江陵一线）：卷二十一《早发白帝城》"朝辞白帝彩云间"；卷二十一《上三峡》《宿巫山下》"三月下瞿塘"；卷二十一《荆门浮舟望蜀江》《秋下荆门》"霜落荆门江树空"；卷三《荆州歌》"白帝城边足风波 / 瞿塘五月谁敢过"；卷三《长干行二首·其一》"瞿塘滟预堆"；卷十三《江上寄巴东故人》"瞿塘饶贾客"；卷七《峨眉山月歌》"夜发清溪向三峡"。
- 交通的**危险性入诗**：瞿塘、滟滪堆＝概率性的死亡，故三峡诗自带惊惧节奏。

### 6.4 蜀道：从制度到《蜀道难》

- 蜀道（金牛道、褒斜道等）在唐代被定为**国驿主道**，唐太宗贞观二十二年诏"开斜谷道水路，运米以至京师"，元和元年宪宗"复置斜谷路馆驿"（马强《论唐宋时期的蜀道管理制度及其特征》）。
- 蜀道北段险要处设"栈道驿"，《元和郡县志》记金牛道"横梁立柱，覆板为路"；李白《蜀道难》所写的"天梯石栈相钩连"，正是**栈道这一交通工程的诗歌形式**。
- **源集《蜀道难》可核引句**（卷二）：
  - 蜀道之难 / 难于上青天（三见，构成复沓）
  - 蚕丛及鱼凫 / 开国何茫然 / 尔来四万八千岁 / 不与秦塞通人烟
  - 西当太白有鸟道 / 可以横绝峨眉巅
  - 地崩山摧壮士死 / 然后天梯石栈相钩连
  - 青泥何盘盘 / 百步九折萦岩峦 / 扪参历井仰胁息 / 以手抚膺坐长叹
  - 连峰去天不盈尺 / 枯松倒挂倚绝壁 / 飞湍瀑流争喧豗
  - 剑阁峥嵘而崔嵬 / 一夫当关 / 万夫莫开
  - 锦城虽云乐 / 不如早还家
- 解读：全篇由**地理（秦蜀交通史）→ 政治（"所守或匪亲，化为狼与豺"）→ 归乡（"不如早还家"）**三段推进；"蜀道"既是实存驿道，也是对"入长安之路"的隐喻。

### 6.5 驿与题诗：诗在路上的存在方式

- 源集直接以驿为题者：卷十三《流夜郎至西塞驿寄裴隐》（"水驿苦不缓"）、卷十八《答裴侍御先行至石头驿以书见招期月满泛洞庭》（"君至石头驿"）、卷二十一《至鸭栏驿上白马矶赠裴侍御》（"临驿卷缇幕"）；卷五《子夜吴歌·冬歌》"明朝驿使发"。
- **含义**：驿馆是唐人的"社交平台"——题壁、赠答、留别都发生在这里，送别诗与干谒诗共享同一物理场景。

## 七、语境 → 创作：可迁移的七条生成规则

1. **场合作诗**：先认场景（饯别／宴饮／投赠／受箓／观妓／题驿），再定语言（乐府体／应制体／古风体）。
2. **干谒的礼貌与傲岸**：前段陈愿、后段自许；结尾的"不平"是性格签名，而非败笔。
3. **隐逸的双面话术**：山水清音＋待召的焦虑，二者必须同时在场才像盛唐。
4. **游仙即退路**：现实挫折一出现，立刻切换蓬莱／瑶台／丹砂的语汇（"弃剑学丹砂"卷十；"早服还丹无世情"卷十三）。
5. **酒与柳是社交货币**：酒写当下（宴），柳写分离（饯）；一热一冷构成唐人情感的双极。
6. **乐府优先**：要写"可以有听众"的诗，就用古题、叠句、长短句；要写"只能给知己看"的诗，才写书怀体（"以诗代书"）。
7. **地理要有工程感**：写山川不写虚景，写驿程、栈道、水驿、瞿塘滟滪——**险是具体的技术名词堆出来的**。
