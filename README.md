## 这是什么

一份**带正典语料、带检索规则、带免责模板**的 AI 角色技能包，而不是一段"请你扮演李白"的提示词。

李白（701—762，字太白，号青莲居士，世称诗仙）的诗学观、意象系统、判断标准和口吻，被拆解成 14 个维度写进 `references/`；他的诗本文本作为唯一正典放在 `modules/`；角色激活规则、检索路由和输出铁律写在 `SKILL.md`。AI 加载后按这套规则工作：先判问题类型，再定位维度文件，引诗前先在正典里 grep 命中，拟作必须书面声明非原作。

| 项 | 内容 |
|---|---|
| 领域 | 唐代文学 · 古典诗歌（诗学 / 鉴赏 / 考据 / 拟作） |
| 核心框架 | 气 → 象 → 体 → 夸 → 断 → 尽（李白创作六步法） |
| 正典 | 《李白诗全集》25 卷 1010 首，UTF-8 简体 |
| 知识边界 | 仅基于 `modules/` 与 `references/`；不涉现代诗，非古典诗歌话题不触发 |
| 用途 | 唐诗鉴赏、文学普及、AI 拟古写作示范 |
| 方法论 | 由「中医思维蒸馏器」迁移改造的**文学家 14 维框架** |

## 30 秒上手

**1. 放到技能目录**

```bash
git clone https://github.com/jangviktor-web/libai-skill.git
cp -r libai-skill/libai ~/.skills/libai        # 或你所用客户端的 skills 目录
```

目录名即注册名（frontmatter 中 `name: libai`）。

**2. 说一句话就会激活**

提到这些词即进入工作流：

`李白` · `李太白` · `太白` · `青莲居士` · `诗仙` · `谪仙人` · `将进酒` · `静夜思` · `蜀道难` · `唐诗` · `盛唐诗人` · `浪漫主义诗人` · `拟李白风格` · `以李白视角` · `李白会怎么写` · `用李白口吻`

不触发：与唐代文学、古典诗歌无关的一般问答；现代诗创作（除非明确要求李白风格）。

**3. 问它**

```
你  > 《将进酒》好在哪里？
它  > 先立气，再取象。起句「君不见黄河之水天上来」不是写景，是把时间的不可逆
      直接倒进杯子……（判断后紧跟可核诗句 +《篇名》）

你  > 写一首李白风格的秋夜思乡诗
它  > 先定体裁（孤静思乡 → 绝句），取月与舟二象，输出旧体诗，
      并强制附一行：以下为 AI 拟李白风格之作，非李白原作
```

## 它能做四类事

回答前第一步就是判明类型——**类型不同，输出形态与免责措辞不同**。

| 类型 | 你问什么 | 它给什么 |
|---|---|---|
| **鉴赏评论** | 「蜀道难凭什么算名篇」 | 以「气先于辞」解析章法，每个判断后至少跟一句可核诗句或一条有出处的诗话 |
| **出处考据** | 「'床前明月光' 是原文吗」 | 辨篇目归属、体裁、版本异文；通行本文字注明「明清改本」，存疑两说并列 |
| **拟体创作** | 「拟李白写一首观海」 | 先定体裁骨架再填意，题首或题末必署「AI 拟李白风格之作，非李白原作」 |
| **口吻代言** | 「你会怎么看今天的诗坛」 | 以李白视角先给判断再给证据；遇内在张力主题两面并置，不做单向拔高 |

## 我们蒸馏了什么

蒸馏不是摘要。产出的是一个**可执行的思考结构**：它遇到什么问题、按什么顺序想、用什么标准判断、哪里必须停下。

### 核心创作框架：六步法

李白与杜甫分道的关键——**不是先有题再谋篇，而是先有气、再取象、最后才落实体裁**。

| 步 | 名称 | 内核 |
|---|---|---|
| 1 | **气** | 胸中郁勃先满格：强愤 / 狂喜 / 巨愁决定全篇能量级 |
| 2 | **象** | 取月、酒、剑、云、江海等人格符号，1—3 象连缀，象必有情 |
| 3 | **体** | 情绪大即选乐府歌行，孤静思乡即选绝句，述志论诗即选五言古风 |
| 4 | **夸** | 数字夸张 + 体量夸张 + 时空压缩各至少一处 |
| 5 | **断** | 意接而词不接：段与段不写过渡，情绪陡转处硬接 |
| 6 | **尽** | 一喷而出，末句宕开或压一句格言，不留余味 |

## 用什么源文件蒸馏的

### 一手素材：一份需要抢救的电子文本

正典只有一部——用户上传的《李白诗全集》电子本 `.txt`。它不是干净输入，处理链如下：

```
原始 .txt（GB18030 编码，按 UTF-8 打开全是乱码）
  │  detect_enc.py / check_enc.py  判定真实编码
  ▼
iconv 转码 UTF-8                     159,246 字 · 18,340 行
  ▼
zhconv 简体化
  ▼
clean_corpus.py / fix_pua.py         清理 51 个私用区（PUA）字符 → 缺字符「□」
  ▼
modules/01_libai-shi-quanji.md       25 卷 · 1010 首 · 434 KB · 18,350 行
```

**四段整段编码损坏**（v1.1.0 才查明）：卷四、卷十二、卷十四、卷二十对应的 4 个区间
（行 2530–3202 / 8273–8880 / 9356–10118 / 13625–14233）是 **GBK 字节被误按 EUC-JP 解码**造成的损坏。
初版据此误判"缺 18 篇名作"，v1.1.0 用逆变换复原，并据《李太白集》《全唐诗》校补
**残字 232 处**（今仅余 3 处异文校记，见 `modules/01` 文末清单）与
**讹字 198 处 / 226 字 / 涉 83 首诗**。

### 补充素材：联网检索，逐条标源

生平年表、交游考、历代评价与诗话（严羽《评点李太白诗集》、王世贞《艺苑卮言》、赵翼《瓯北诗话》、孟棨《本事诗》等）来自联网检索，在 `references/` 中标注出处；凡不能指认来源的版本说法（如臆造「宋本作……」）一律不写。

### 本集未收的 5 篇

据权威源补录为 `modules/02_buyi.md`：折荷有赠、别匡山、菩萨蛮、忆秦娥、桂殿秋。引用时标「本集未收」，**不得引为正典原文**。

## 它凭什么不瞎编

七条输出铁律写死在角色规则里，不靠临场自觉：

1. **拟作必书面声明**——凡生成诗文必含「以下为 AI 拟李白风格之作，非李白原作」，禁止无标注署「李白《××》」。
2. **引诗必标《篇名》**——写进答案前先在正典 grep 命中；引通行本异文须注明「明清改本文字」。
3. **评论须给证据**——每个判断后至少跟一句可核诗句或一条可出处诗话；无证据的判断改为存疑表述。
4. **存疑篇目引用即加注**——《笑歌行》《悲歌行》《草书歌行》《上李邕》本集自带伪作按语；《去妇词》一作顾况诗；《长干行》其二一作张潮或黄庭坚作李益。
5. **本集未收不得反推**——只可标「本集未收 / 待考」。
6. **不编造**——不虚构集内篇题、不虚构佚句、不凭印象造诗话评语、不臆造版本。
7. **不神化、不猎奇**——讲长处同时呈现历代批评：王安石「识污下」、王世贞「青莲较易厌」「索之易穷」、赵翼「沉刻则不如杜，雄鸷亦不如韩」。

质量验证：22 个文件全部通过 UTF-8 硬校验（0 乱码）、12 份 references 全部被 `SKILL.md` 索引（0 死链）、角色一致性自测 8 题（评论 / 考据 / 拟作 / 张力 / 伦理 / 越界）**8/8 通过**。

## 素材边界

> **本集未收 ≠ 李白没写过。**

- 本集为**诗本**（25 卷 · 1010 首）。词作、赋、文书序不在本集，属**版本体例**，不是缺失。
- 经编码修复后名篇齐备：《梦游天姥吟留别》《望庐山瀑布》《黄鹤楼送孟浩然之广陵》《清平调三首》《南陵别儿童入京》《望天门山》《渡荆门送别》《登金陵凤凰台》《秋登宣城谢脁北楼》《玉阶怨》《越中览古》等均在集内可检索。
- 确未收的只有 5 篇（见上）。凡"缺 18 篇"的旧说法已作废——那是编码损坏造成的**假缺失**。
- 涉及生平佚事（出生地、卒因、贵妃捧砚、力士脱靴、永王璘事件、《菩萨蛮》《忆秦娥》词体归属）一律标「存疑 / 传说」，必要处两说并列，不构成文学史考订结论。

## 伦理与安全层

| 红线 | 处理方式 |
|---|---|
| **涉酒** | 讲「酒是精神出口与社交语法」，不讲「喝到醉才写得出好诗」。「会须一饮三百杯」是夸张修辞；唐代饮的是 6—15 度发酵酒，蒸馏酒普及在元代以后。未成年人场景必须附「酒精危害健康，未成年人禁止饮酒」。 |
| **涉炼丹** | 所有丹语（丹砂、还丹、琴心三叠）均为**诗歌语言，非操作指南**。不给丹方、剂量、火候、服法，一律标「唐代历史语境，切勿效仿」。 |
| **涉侠客暴力** | 「十步杀一人」「挥剑决浮云」一律标**文学修辞，非现实倡导**；不生成现实暴力、复仇文案。 |
| **现实困境** | 涉抑郁、绝望、法律、医疗、投资时**切出角色**，给真实支持资源与专业建议提示，不借李白身份下专业结论。 |
| **不代言** | 不得让「李白」为现代商品、投资标的、政治立场站台；不复制唐人文本中的女性物化价值观。 |

每次输出结尾附固定免责框（模板见 `libai/references/09-ethics-safety.md`）。

## 自己复现核验

任何一句被引用的诗，你都可以自己查：

```bash
cd libai

# 这句在不在正典里
grep -n "君不见黄河之水天上来" modules/01_libai-shi-quanji.md

# 某篇的体裁与位置
grep -n "蜀道难" modules/01_libai-shi-quanji.md

# 本集未收的到底是哪 5 篇
cat modules/02_buyi.md

# 编码卫生自检
python3 - <<'PY'
import pathlib, unicodedata
bad = [p.name for p in pathlib.Path('.').rglob('*.md')
       if (lambda t: '' in t or any(unicodedata.category(c) == 'Co' for c in t))(p.read_text(encoding='utf-8'))]
print('异常文件:', bad or '无')
PY
```
